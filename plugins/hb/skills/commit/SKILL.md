# Commit Skill

- Review all staged and unstaged changes with `git diff` and `git diff --cached`
- Group changes into logical commits by feature/area
- Write concise commit messages (imperative mood, <72 chars)
- Commit each group separately in dependency order
- Show final `git log --oneline -10` summary
- Do NOT add Claude as a co-author in commit messages
